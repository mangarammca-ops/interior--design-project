# 🏡 Interior Design Website

A modern and elegant Interior Design Website created using HTML, CSS, and JavaScript. This website showcases beautiful interior spaces, creative home designs, and professional interior decoration services.

## 🌟 About The Project

This project is designed to present modern interior design ideas for homes, bedrooms, living rooms, kitchens, and offices. It features an attractive layout with stylish colors, beautiful images, and smooth animations.

## ✨ Features

- Modern and Professional UI Design
- Home Page with Attractive Hero Section
- About Us Section
- Interior Design Services
- Beautiful Project Gallery
- Modern Bedroom & Living Room Designs
- Kitchen Interior Designs
- Contact Form
- Responsive Website Layout

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How To Run

1. Download or clone this repository.
2. Open the project folder.
3. Find `index.html`.
4. Open it in your browser.
5. Explore the Interior Design Website.

## 🎯 Project Purpose

The main purpose of this project is to practice frontend web development and create a professional interior design website using basic web technologies.
